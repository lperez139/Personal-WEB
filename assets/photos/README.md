# Fotos reemplazables

Sube tus fotos a esta carpeta usando estos nombres para que la web las tome automaticamente:

- `lukas-hero.jpg`
- `project-simple-retail-vision.jpg`
- `project-skyterra.jpg`
- `project-skyesits.jpg`
- `project-ojodecondor.jpg`
- `strip-01.jpg`
- `strip-02.jpg`
- `strip-03.jpg`
- `strip-04.jpg`

Mientras un archivo no exista, la web usa una foto remota de fallback.

Puedes usar `.jpg`, `.jpeg`, `.png` o `.webp`, pero si cambias la extension tambien hay que actualizarla en `index.html`.
