# Web personal de Lukas Perez

Abre `index.html` en el navegador para ver la web.

Archivos principales:

- `index.html`: contenido, textos, proyectos y contacto.
- `styles.css`: diseño responsive y animaciones.
- `script.js`: fallbacks de fotos y pequenos efectos.
- `assets/photos/`: carpeta lista para subir tus fotos.

Para cambiar fotos, sube imagenes a `assets/photos/` usando los nombres indicados en `assets/photos/README.md`.

Para completar despues:

- Reemplazar `tu-email@dominio.com` por tu email real en `index.html`.
- Cambiar `Descripcion pendiente.` por la descripcion de cada proyecto.
